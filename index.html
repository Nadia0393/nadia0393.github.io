Projects.

01 — MLOPS · FLAGSHIP
IT Infrastructure Anomaly Detection & Predictive Incident System

End-to-end MLOps pipeline for real-time infrastructure anomaly detection. Ingests multivariate server telemetry (CPU, memory, disk I/O, network) into Delta Lake via Medallion Architecture with schema enforcement and ACID-compliant writes. Engineered time-series features (rolling mean, std, rate-of-change across 5/15/60-min windows) stored in Databricks Feature Store for point-in-time serving. XGBoost and Isolation Forest classifiers tracked in MLflow, best model deployed to a real-time scoring endpoint. Automated retraining triggered by Evidently AI drift detection. GitHub Actions CI/CD with data validation gates and staged promotion logic.
